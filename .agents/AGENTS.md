# Vision Zero Chicago Workspace Rules

Before planning, editing, testing, or reporting completion, read and obey @/AGENTS.md. Treat its completion gates as mandatory. A task is incomplete unless executable verification passes.

When reporting status, framing tasks, or writing documentation, always explicitly distinguish between:

1. **Current verified state**: Facts, metrics, contracts, and outputs that have been executed and validated.
2. **Current-task changes**: Code, configuration, or documentation modifications made specifically within the active task scope.
3. **Future planned functionality**: Methodological, spatial, modeling, or optimization steps that are scheduled for upcoming phases but not yet implemented or verified.
