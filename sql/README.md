# Vision Zero Chicago SQL Analytical Layer

## Overview

This directory contains the DuckDB SQL analytical scripts for the Vision Zero Chicago decision-support system.

DuckDB was selected as the repository's local SQL analytical and Power BI serving engine because it:
1. Executes high-performance analytical queries directly over Parquet files without requiring a external database server.
2. Supports standard SQL window functions, CTEs, and aggregation necessary for independent feature auditing.
3. Serves as a zero-overhead local data mart for Power BI desktop and reporting pipelines.

## Source-of-Truth Governance

- **Analytical Source of Truth**: Validated Parquet outputs (`data/processed/corridor_month_panel.parquet` and `data/processed/corridor_month_features.parquet`) generated by the Python data pipeline remain the single source of truth.
- **SQL Layer Role**: DuckDB views, audits, and database tables are reproducible derived surfaces used for independent quality assurance, parity testing, and Power BI reporting.
- **Artifact Preservation**: Generated database files (`data/processed/vision_zero_analytics.duckdb`) and exported SQL marts (`data/processed/power_bi_corridor_history.parquet`) are ephemeral generated artifacts protected by `.gitignore` and are not committed to Git.

## Execution Order

The SQL analytics pipeline executes in numbered sequence:

1. `01_create_source_views.sql`: Registers DuckDB views over the authoritative Parquet panel and feature files.
2. `02_corridor_month_feature_audit.sql`: Independently reproduces lag and rolling window features from the raw panel using SQL window functions (`LAG()`, `ROWS BETWEEN n PRECEDING AND 1 PRECEDING`).
3. `03_data_quality_reconciliation.sql`: Executes 21 automated SQL reconciliation and data-quality checks.
4. `04_power_bi_corridor_history_mart.sql`: Constructs and exports the 4,128-row Power BI historical analytical mart to `data/processed/power_bi_corridor_history.parquet`.

## Python Orchestration and Validation

- **Pipeline Execution**: `python src/data/build_sql_analytics_mart.py`
- **Quality & Parity Validation**: `python src/validation/validate_sql_analytics_mart.py`
- **Automated Tests**: `pytest tests/test_sql_analytics_mart.py`
